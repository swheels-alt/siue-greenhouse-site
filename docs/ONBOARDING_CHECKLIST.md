# New developer checklist

Copy into an issue labeled `onboarding` for each new person (QA plan 5.3 and Appendix B).

- [ ] Day 1: GitHub organization, project board and team chat access granted; buddy named
- [ ] Day 1: Read README.md, docs/DEFINITION_OF_DONE.md, CONTRIBUTING.md and docs/LESSONS.md
- [ ] Day 1: Timed setup on a clean machine or new user account, from docs/SETUP.md alone. Start
      the timer at `git clone` and stop it when `make test` passes (goal: 30 minutes with the
      prerequisites installed, 2 hours including them). Record the run, every stop and the date in
      docs/qa/onboarding-tests/YYYY-MM-DD-name.md from the TEMPLATE there
- [ ] Day 1: First task: issue #3, "Home page: show greenhouse location and hours"
      (docs/qa/issues/0003-home-page-location-and-hours.md until it is on GitHub). It is a real,
      small change, sized to finish on day one: one component, one test, one CHANGELOG line, and
      the PR opened by the end of the day, reviewed like any other
- [ ] Day 2: Read docs/QA_PLAN.md, docs/ARCHITECTURE.md and docs/DATABASE.md; review one PR with
      your buddy
- [ ] Week 1: SIUE accessibility training complete (QA plan 9.6)
- [ ] Week 1: Join the review rotation (docs/ROTATION.md) and pick up a second `good first issue`
